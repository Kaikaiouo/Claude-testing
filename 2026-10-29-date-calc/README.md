# 日期計算器 (date-calc)

命令列日期小工具:算兩日相差天數、加減天數、查星期幾、倒數日、當年度進度條。使用 Node.js,不需安裝任何套件。

## 執行

```bash
node datecalc.js diff 2026-01-01 2026-10-29   # 相差天數
node datecalc.js add 2026-10-29 100           # 加(或減,用負數)天數
node datecalc.js weekday 2026-10-29           # 星期幾
node datecalc.js countdown 2027-01-01         # 距今倒數(可用 today 代表今天)
node datecalc.js progress 2026-10-29          # 年度進度
node test.js                                  # 執行測試
```

## 範例輸出

```
2026-01-01 → 2026-10-29:301 天(約 43.0 週)
2026-10-29 + 100 天 = 2027-02-06(星期六)
2026-10-29 是星期四
2026-10-29 是 2026 年第 302/365 天
[█████████████████░░░] 82.7%
距離 2027-01-01 還有 65 天
```

日期格式為 `YYYY-MM-DD`,會檢查不存在的日期(如 2026-02-30),並正確處理閏年。
