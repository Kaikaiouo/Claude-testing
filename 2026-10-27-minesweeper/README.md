# 💣 踩地雷 (Minesweeper)

純 HTML + JavaScript 的踩地雷小遊戲,不需安裝任何套件。

## 檔案
- `index.html`:遊戲介面(用瀏覽器直接開啟即可)
- `core.js`:核心邏輯(佈雷、翻格、連鎖展開、勝利判定)
- `test.js`:Node.js 單元測試

## 執行
```bash
# 玩遊戲:用瀏覽器開啟 index.html
# 執行測試:
node test.js
```

## 玩法
- 左鍵翻開格子,右鍵插旗標記地雷。
- 第一步及其周圍 8 格保證沒有地雷。
- 有初級 9×9(10 雷)、中級 12×12(25 雷)、高級 16×16(40 雷)三種難度。
- 翻開所有非地雷格即獲勝。
