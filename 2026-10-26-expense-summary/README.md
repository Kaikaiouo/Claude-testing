# 記帳 CSV 統計工具

讀取記帳 CSV(欄位:日期、類別、金額),依類別與月份彙總支出,並以文字長條圖顯示佔比。

## 執行方式

只需 Python 3,不需安裝套件:

```bash
python3 expense.py sample.csv   # 產生報表
python3 test_expense.py         # 執行測試
```

CSV 格式:

```
日期,類別,金額
2026-09-03,餐飲,150
```

## 範例輸出

```
總支出: 9,530 元 (8 筆)

[依類別]
房租        8,000  83.9% █████████████████
娛樂          800   8.4% ██
餐飲          550   5.8% █
交通          180   1.9% 

[依月份]
2026-09      930 ██
2026-10    8,600 ████████████████████
```
