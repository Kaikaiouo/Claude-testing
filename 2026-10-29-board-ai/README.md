# 棋類 AI:黑白棋 + 五子棋 (board-ai)

用同一套 **Negamax + Alpha-Beta 剪枝** 搜尋引擎,同時驅動兩款棋類遊戲的 AI。純 JavaScript(Node.js 18+),不需安裝任何套件,可在終端機或瀏覽器(Canvas)與 AI 對戰。

## 快速開始

```bash
node --test test/*.test.js            # 執行 42 個測試
node cli.js play othello              # 終端機與黑白棋 AI 對戰(輸入 d3 這類座標)
node cli.js play gomoku --depth 3     # 五子棋(輸入 H8 這類座標,不含字母 I)
node cli.js arena othello --games 10 --depth1 5 --depth2 2   # AI 互打,測試強弱
node bench.js                         # 效能基準
```

瀏覽器版:直接用瀏覽器開啟 `index.html`(不需伺服器),可選遊戲、先後手、難度,並支援悔棋。

`play` 選項:`--color black|white`、`--depth N`、`--time 每步毫秒上限`、`--size 棋盤大小(五子棋)`。

## 架構

```
src/util.js      mulberry32 可重現亂數、Zobrist 雜湊表
src/othello.js   黑白棋規則(位元安全的 play/undo、PASS、終局判定)與評估函式
src/gomoku.js    五子棋規則(自由規則,可調棋盤 5~19)、候選步產生與評估函式
src/search.js    通用搜尋引擎:Negamax、Alpha-Beta、置換表、迭代加深、時間限制
src/players.js   隨機玩家、AI 玩家、playGame 對戰迴圈
cli.js           終端機對戰與 arena 對戰統計
index.html       Canvas 網頁介面(與命令列共用 src/ 下的同一份程式)
test/            42 個測試(規則、雜湊、搜尋正確性、AI 強度)
```

兩款遊戲都實作同一個介面(`isOver / terminalScore / evaluate / searchMoves / play / undo / hash`),搜尋引擎因此完全不知道自己在下哪種棋。分數一律從「輪到走棋的一方」角度計算,所以用 Negamax 即可。

### 搜尋引擎

- **Alpha-Beta 剪枝**:好的走法排序讓剪枝效率大增。
- **置換表**:以 Zobrist 雜湊(兩組 32 位元合成約 53 位元的鍵)快取已搜尋局面,並儲存精確值 / 下界 / 上界與最佳步,最佳步會優先搜尋。
- **迭代加深**:由淺到深逐層搜尋,每層結果成為下層的走法排序依據;超過時間限制時回傳上一層完成的最佳步。
- **速勝偏好**:終局分數會依步數調整,同樣能贏時選最快的、必輸時盡量拖延。找到必勝/必敗就提前結束。
- **play/undo 而非複製棋盤**:搜尋過程不配置新物件,雜湊以 XOR 增量更新。

### 黑白棋評估

位置權重表(角落極高、角落旁的 X/C 格為負,角落被佔後該懲罰解除)+ 行動力差(雙方可下步數)+ 殘局(空格 ≤ 12)加重棋子數。候選步依位置權重排序,角落優先。無子可下時 `legalMoves()` 回傳 `[PASS]`,雙方皆無步才算結束。

### 五子棋評估

- 掃描全盤所有「五格視窗」:視窗內只有單一顏色時,依棋子數 `[0, 1, 10, 100, 1000, 100000]` 計分,黑白相減。活三自然比死三分數高(涵蓋它的有效視窗較多)。
- **候選步**:只考慮與現有棋子距離 ≤ 2 的空格,再依「己方得分 + 0.95 × 對手在此落子的得分」排序,最多保留 `maxBranch`(預設 12)個。
- **必勝/必擋剪枝**:若某步能直接連成五子就只搜它;若對手下一手會連成五子,只搜擋住的步。大幅縮小分支數,又不會漏掉戰術。

## 測試與驗證

`node --test test/*.test.js` 涵蓋:

- 規則:初始局面、翻轉、非法步、PASS、終局與平手、五個方向的五連、長連、被截斷、座標解析。
- 資料結構:隨機對局中「增量雜湊 = 重新計算的雜湊」、完整復原後局面與雜湊還原、clone 獨立。
- 搜尋正確性:Alpha-Beta(含/不含置換表)的分數與無剪枝的純 minimax **完全一致**(黑白棋多個隨機局面、五子棋小棋盤);搜尋後局面不變;時限內必有合法步。
- 戰術:五子棋 AI 會直接取勝、擋四連、用活三做出必勝活四。
- 強度:黑白棋深度 4 贏隨機玩家 ≥ 5/6、深度 4 勝過深度 1;五子棋深度 2 在 9x9 贏隨機玩家 ≥ 3/4。

## 已知限制

- 五子棋是自由規則,黑棋先手優勢明顯,沒有禁手規則。
- 五子棋評估是視窗計分,不辨識「活」「死」形態的細微差別,也沒有威脅空間搜尋(VCF/VCT),深度 4 以上較強但仍會漏掉長手數的連續進攻。
- 黑白棋沒有開局庫與終局精確求解;評估函式是手調權重,非機器學習而來。
- 網頁版 AI 在主執行緒中計算(有 4 秒時限),高難度時瀏覽器會短暫停頓。
